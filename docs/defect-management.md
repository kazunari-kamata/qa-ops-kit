# 障害管理ガイド

障害票には、事象、期待結果、実際の結果、再現手順、影響、優先度、発見環境を記録します。推測と確認済みの事実を分け、対応完了後は修正確認と回帰確認の結果を残します。

| 優先度 | 例 | 初動 |
| --- | --- | --- |
| Critical | 利用開始や重要業務を妨げ、回避策がない | 直ちに責任者へ連絡し、リリース判断に反映 |
| High | 主要機能への影響が大きい | 原因・回避策・修正予定を合意 |
| Medium | 回避策がある、または一部機能への影響 | 計画に従って対応 |
| Low | 軽微な表示・改善要望 | 優先度を確認して管理 |

優先度は重大度と緊急度を含む案件固有の判断です。件数だけで品質を判断しません。
